# 悟空质量价值指数 - 公网研究版

这是“悟空质量价值指数”的公开研究网站源码。网站展示收盘后的指数层净值、历史表现、行业汇总和已审核的因子研究摘要，供学习、复盘与长期记录使用。

## 公开边界

本仓库只保存指数与行业汇总层的审核快照；单证券、交易执行、私有账本、行情路径、凭据和其他非公开研究材料均不在本仓库内。

公开数据由本地研究后台在每个交易日收盘后生成。只有价格一致性、PIT时点和公开白名单均通过时，才会把经过审查的聚合快照同步到本网站。网站不会连接券商，也不会提交真实证券订单。

## 本地运行

```bash
pnpm install
pnpm build
```

构建前可运行以下命令，确认拟提交的Git文件不含敏感数据：

```bash
python scripts/validate_public_repository.py
```

## 研究声明

本项目为量化研究资料与历史记录，不构成投资建议、收益承诺或任何证券交易指令。历史结果不代表未来表现。使用者应独立判断并自行承担投资风险。
